# HTB Writeups

Разборы лабораторных машин Hack The Box: путь от первоначального доступа до root или Administrator, доказательства каждого перехода и выводы для защиты.

Автор: [d7n98jhk52-debug](https://github.com/d7n98jhk52-debug) · [Профиль HTB](https://app.hackthebox.com/public/users/4100352)

| Машина | ОС | Сложность по снимку HTB | Основные темы | Результат |
|---|---|---|---|---|
| [Bedside](writeups/bedside.md) | Linux | Medium | PDF/CMap, pickle, Path Traversal, SSH, MONAI checkpoint | User и Root owned |
| [DanglingTree](writeups/danglingtree.md) | Windows | Medium | WAC, сервисные credentials, DPAPI, AD ACL, AD CS | User и Root owned |

## Как читать

Каждый разбор содержит последовательность действий, подтверждённый результат, ограничения доказательств и меры защиты. Скриншоты HTB подтверждают принятие обоих флагов для обеих машин. Значения флагов, пароли, приватные ключи, сертификаты с закрытыми ключами и Kerberos-билеты не публикуются.

Материалы относятся к лаборатории HTB. Названия пользователей, доменов и внутренние адреса в технических иллюстрациях относятся к стенду. Это описания конкретных прохождений, а не заявление об обнаружении новых уязвимостей в продуктах.

## Структура

- `writeups/` — два райтапа на русском языке.
- `assets/` — проверенные иллюстрации и подтверждения результата.

Полные исходные отчёты и рабочие артефакты эксплуатации в репозиторий не включены. В райтапах отдельно обозначено, какие детали не подтверждены исходными доказательствами.
